| Operation ID | Operation | Purpose |
|---|---|---|
| OP-01 | Perform Sensor Self-Check | Verify that all essential sensors and environmental-control devices are working correctly. |
| OP-02 | Start Environmental Monitoring | Begin continuous monitoring of the chamber's environmental conditions. |
| OP-03 | Register Artifact Information | Record the identification information of the artifact placed inside the chamber. |
| OP-04 | Load Environmental Profile | Load the required environmental limits for the artifact. |
| OP-05 | Verify Chamber Door Status | Confirm that the chamber door is closed before active conservation begins. |
| OP-06 | Start Conservation Control | Activate normal conservation activities when all required conditions are satisfied. |
| OP-07 | Compare Environmental Readings | Compare actual temperature and humidity with the artifact's permitted limits. |
| OP-08 | Correct Temperature | Attempt to restore temperature when it moves outside the permitted range. |
| OP-09 | Verify Temperature Recovery | Verify through sensor readings that the required temperature has been restored. |
| OP-10 | Correct Humidity | Attempt to restore humidity when it moves outside the permitted range. |
| OP-11 | Verify Humidity Recovery | Verify through sensor readings that the required humidity has been restored. |
| OP-12 | Activate Artifact Protection | Protect the artifact when an environmental condition cannot be corrected within the allowed recovery period. |
| OP-13 | Generate Operator Alert | Notify the museum operator when artifact protection is required. |
| OP-14 | Detect Significant Vibration | Detect significant vibration while an artifact is inside the chamber. |
| OP-15 | Suspend Risk-Increasing Activities | Temporarily suspend activities that could increase the risk to the artifact. |
| OP-16 | Verify Vibration Stabilization | Confirm that vibration remains below the permitted threshold for the required stabilization period. |
| OP-17 | Suspend Conservation on Door Opening | Immediately suspend normal conservation activities when the chamber door is opened. |
| OP-18 | Verify Conditions After Door Closure | Verify environmental conditions and sensor status before conservation can resume. |
| OP-19 | Switch to Emergency Power | Switch to the emergency power source when normal power is lost and emergency power is available. |
| OP-20 | Record Power Failure Incident | Record the power-loss incident when emergency power is unavailable. |
| OP-21 | Perform Safe Shutdown | Place the system in a safe shutdown condition when required power is unavailable. |
| OP-22 | Confirm Safe Artifact Removal | Confirm that the chamber is safe and no active protection response exists before artifact removal. |
